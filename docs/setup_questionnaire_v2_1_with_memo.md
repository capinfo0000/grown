# Mirror セットアップアンケート v2.1

## 設計方針

**役割分担：**

- アンケート = 抽象的・自己認識（過去データから取れないもの）
- 過去データ抽出 = 具体的・行動の蓄積
- メモ機能 = いつでも追加できる「クローンへの覚書」

**核心：**

- 心がけセクション（マイルール集）を厚くし、クローンの「人格のガードレール」を作る
- メモ機能で、アンケートでカバーしきれない情報を後からいくらでも追加できる

**ボリューム：**

- 全28問・5セクション・約10分（全部やる場合）
- セクション1（5問・2分）でも最低限のクローンが作れる
- 段階的解放、進捗表示で離脱防止

## セットアップ完了後の継続機能：「クローンへのメモ」

### 概要

セットアップ後も、いつでも追加できるメモ機能。
ダッシュボード or 設定画面からアクセス。

### 仕様

```
[メモ追加画面]
├─ メモ内容（自由記述）
└─ [保存]ボタン

[保存後]
クローン（LLM）が内容を分析し、タグを自動付与
例：「最近、転職した」 → タグ: ["状況変化", "仕事"]
```

### データ構造

```json
{
  "memos": [
    {
      "id": "memo_001",
      "content": "Aさんとは関係性が深いから、対応は柔らかく",
      "tags": ["対人配慮", "関係性"],
      "created_at": "2026-05-05T10:30:00Z",
      "updated_at": "2026-05-05T10:30:00Z"
    },
    {
      "id": "memo_002",
      "content": "最近、新しいプロジェクトを始めた",
      "tags": ["状況変化", "仕事"],
      "created_at": "2026-05-08T15:20:00Z",
      "updated_at": "2026-05-08T15:20:00Z"
    }
  ]
}
```

### 管理機能

- メモの一覧表示（タグでフィルタ可能）
- 編集・削除
- 順序の並べ替え
- 検索（テキスト・タグ）

### 応答時の活用

- メンバーから質問が来たとき、関連性の高いメモを自動的に参照
- メモの内容が応答に反映される
- 古いメモは「もう無効？」と確認するUI（オプション）

## 設計上の補足

### 「心がけ重視」の意義

**過去データから取れること（具体性）：**

- 実際の判断事例
- 具体的な口調
- 関わった人・トピック

**心がけだけが取れること（抽象性）：**

- 意識的に守っているルール
- 自分への約束
- 価値観の明示的な表現

→ これがアンケートの存在意義の核

### メモ機能の戦略的意義

**初回セットアップを軽くしながら、深い情報を取れる仕組み：**

- 30問でも10分なので、それほど重くない
- 足りない部分はメモで後から補完できる
- ユーザーは「使いながら育てる」体験ができる

**運用面の柔軟性：**

- 「最近の状況」を反映できる
- 特定の人への配慮を後から追加できる
- 季節・時期的な事情も反映できる

### プロンプトとの連携

このアンケートのデータは：

- 心がけセクション → 応答プロンプトの「絶対ルール」として組み込み
- 価値観セクション → 判断軸として組み込み
- 強み・印象 → クローンの「らしさ」として組み込み
- 境界線 → 答えない領域として明示
- メモ → 状況依存の追加コンテキストとして毎回参照
