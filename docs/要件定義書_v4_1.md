## 2. セットアップアンケート v2.1（更新）

### 2.1 設計方針の変更

第4版時点では「アンケートを軽く・基本情報中心」の方針だったが、ユーザー指示により以下の方針に変更した。

- **役割分担**：アンケート＝抽象的な自己認識、過去データ抽出＝具体的な行動蓄積
- 過去データから取れる「具体性」はアンケートで聞かない
- 「心がけ」セクションを核にする（マイルール集として）
- メモ機能で「アンケートでカバーしきれない情報」を後から追加可能に

### 2.2 アンケート全体構成

| セクション | 問数 | 位置づけ | 内容 |
|---|---|---|---|
| S1：基本情報 | 5問 | 必須 | 名前・年代・職業・業界・役職 |
| S2：価値観 | 5問 | 推奨 | 価値観・譲れない/避けたいこと・判断軸・ストレス源 |
| S3：心がけ | 14問 | 最重要 | シーン別の心がけ。クローン応答のガードレール |
| S4：強み・印象 | 3問 | 任意 | 自己認識の強み・苦手・周囲からの印象 |
| S5：境界・メモ | 3問 | 任意 | 答えない領域・配慮事項・初期メモ |
| **合計** | **30問** | **約10分** | 全部やる場合の所要時間 |

詳細は別ファイル「setup_questionnaire_v2_1_with_memo.md」を参照。

### 2.3 段階的解放

セクション1（5問）だけで最低限のクローンが作成可能。残りは段階的に進められ、進めるほど応答精度が上がる。

- **S1完了**：「最低限のクローン作成可能」表示
- **S2完了**：「価値観プロファイル完成」表示
- **S3完了**：「心がけプロファイル完成、人格のガードレール整備」表示
- **S4完了**：「自己認識データ完成」表示
- **S5完了**：「セットアップ完了」表示

各セクション完了時に進捗％を表示し、離脱を防ぐUX設計とする。

## 3. メモ機能（新規追加）

### 3.1 概要

クローン主が、アンケートでカバーしきれない情報を、いつでも追加できる「クローンへの覚書」機能。

- セットアップ時に初期メモを追加可能（S5のQ30）
- セットアップ後も、ダッシュボードからいつでも追加・編集・削除
- メモ追加時、クローンが内容を分析しタグを自動付与
- 応答時、関連性の高いメモが自動参照される

### 3.2 ユースケース

**【シーン1：新しい状況の反映】**

- 「最近、転職して新しいプロジェクトを始めた」
- 「この半年は健康問題に取り組んでいる」

**【シーン2：特定の相手への配慮】**

- 「Aさんとはこういう関係性だから、対応は柔らかく」
- 「Bさんには厳しめに、率直に伝えてほしい」

**【シーン3：時期的な配慮】**

- 「今は繁忙期だから、長文はNG」

**【シーン4：自分への約束】**

- 「今年は『NOと言える自分』を目指してる」

### 3.3 データ構造

メモは `memos.json` として保管される。詳細は「data_schema_v1.md」を参照。

| フィールド | 型 | 説明 |
|---|---|---|
| id | string | メモのユニークID |
| content | string | メモ本文（最大500字） |
| tags | array<string> | 自動付与タグ（クローンが分類） |
| created_at | ISO8601 | 作成日時 |
| updated_at | ISO8601 | 更新日時 |
| active | boolean | 有効フラグ（無効化対応） |

### 3.4 制約

- 1メモあたり最大500文字
- タグは最大10個（自動付与）
- 1ユーザーあたり最大100メモ
